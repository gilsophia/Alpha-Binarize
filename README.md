# Alpha-Binarize 透明度二值化（Photoshop 扩展）v1.0.0

一个把图层像素的透明度（alpha）按阈值强制二值化的 Photoshop 面板插件：
每个像素要么 100% 不透明，要么完全透明（0%）。可选同时把颜色也二值化为纯黑 / 纯白。

## 功能

- 透明度阈值二值化（阈值 1–255 可调）
- 可选：颜色二值化（纯黑 / 纯白）
- 可选：保留图层蒙版（非破坏性，便于之后微调）
- 支持多选图层批量处理
- 整次操作可用一次 Ctrl+Z 撤销

## 安装

1. 运行本安装包（Alpha-Binarize 透明度二值化 v1.0.0 安装包.exe）
2. 阅读《说明》和《许可协议》，勾选同意后点击「安装 / 更新」
3. 安装包会自动卸载电脑里已有的本插件，然后安装新版本
4. 也可以使用本安装包来卸载本插件（点击「卸载」）

## 使用

1. 重启 Photoshop
2. 打开菜单：窗口(W) > 扩展功能 > 透明度二值化
3. 打开文档，选择要处理的图层（可多选）
4. 设置阈值与选项后，点击「对选中图层执行」

## 兼容性

- Windows + Adobe Photoshop 2020（CEP 9）及以上版本
- 安装位置：%AppData%\Adobe\CEP\extensions\com.alpha.binarize.panel
